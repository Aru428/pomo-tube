# PomoTube

유튜브 영상을 보면서 뽀모도로 타이머를 한 화면에서 쓰는 개인용 웹앱이에요.

- 유튜브 영상 또는 플레이리스트 링크를 붙여넣으면 영상이 임베드돼요
- 집중 25분 / 짧은 휴식 5분 / 긴 휴식 15분 (설정에서 변경 가능), 4번 집중하면 긴 휴식
- 다크 모드가 기본이고, 헤더 버튼으로 라이트 모드로 전환해요
- 마지막 영상 링크, 시간 설정, 테마, 오늘 완료 횟수는 브라우저에 저장돼요

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인해요.

## 배포

GitHub 레포를 Vercel에서 Import하면 돼요. 별도 설정은 필요 없어요.

## 안내

- PomoTube는 YouTube와 관련 없는 비공식 개인 프로젝트예요. 영상은 YouTube의 공식 임베드 플레이어로 재생돼요.
- 서버로 보내거나 저장하는 정보가 없어요. 영상 링크, 설정, 테마, 완료 횟수는 사용자 브라우저(localStorage)에만 저장돼요.
- 영상 주인이 임베드를 막아 둔 영상은 재생되지 않을 수 있어요.
